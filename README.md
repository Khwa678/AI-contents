# 🚀 AI ContentOps System

## 📌 Overview

The **AI ContentOps System** is a multi-agent AI platform designed to automate the complete lifecycle of enterprise content operations. From content generation to compliance checking, localization, and distribution, this system streamlines workflows and significantly reduces manual effort. Built as part of the ET AI Hackathon 2026, the project demonstrates how AI agents can collaborate to deliver high-quality, consistent, and scalable content solutions.

---

## 🎯 Problem Statement

Organizations today face challenges in managing content efficiently. Content creation, compliance validation, translation, and distribution are often handled manually, leading to delays, inconsistencies, and increased operational costs. There is a need for an intelligent system that can automate this entire pipeline while maintaining quality and compliance.

---

## 💡 Solution

This project introduces a **multi-agent AI system** where each agent performs a specific task in the content lifecycle:

* ✍️ **Content Generator Agent**: Generates professional content based on user input using AI models.
* ⚖️ **Compliance Agent**: Ensures content adheres to guidelines, checks for harmful or misleading information.
* 🌍 **Localization Agent**: Translates content into different languages (e.g., Hindi) using AI.
* 📢 **Distribution Agent**: Formats and optimizes content for platforms like LinkedIn.

These agents work sequentially to deliver a fully processed output, simulating real-world enterprise workflows.

---

## ⚙️ Tech Stack

* **Frontend**: React (Vite) + Tailwind CSS
* **Backend**: Node.js + Express
* **AI Integration**: OpenRouter API (LLaMA / OpenChat models)
* **Other Tools**: Axios, dotenv

---

## 🔄 Workflow

1. User enters a content idea
2. Content Generator creates initial draft
3. Compliance Agent validates content
4. Localization Agent translates content
5. Distribution Agent formats final output
6. Results are displayed with impact metrics

## 🚀 How to Run

### 1. Clone Repository

```bash
git clone https://github.com/your-username/ai-contentops.git
cd ai-contentops
```

### 2. Setup Backend

```bash
cd backend
npm install
```

Create a `.env` file:

```
OPENROUTER_API_KEY=your_api_key_here
```

Run backend:

```bash
node server.js
```

---

### 3. Setup Frontend

```bash
cd frontend
npm install
npm run dev
```
